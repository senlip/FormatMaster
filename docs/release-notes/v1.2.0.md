# FormatMaster v1.2.0

> 万能格式转换器 · 视频 / 音频 / 图像 / 文档 / 压缩包 · Windows 10 / 11

本次修掉两个**用户明明能碰到、自动化测试却全绿**的 bug，并把这两类问题
各自补上了会自动失败的回归测试。

---

## 一、修复：docx → pdf 变成一坨乱码

上版报告「docx 转 pdf 之后乱码」。排查下来不是"编码猜错"，是**两处独立故障叠加**：

| # | 症状 | 真凶 |
|---|---|---|
| 1 | 所有 Office 文档**从未走过**高保真通道，一直在静默降级 | `_com_dispatch` 里把传入的模块当属性访问（`win32com.client.client.DispatchEx`），抛出的 `AttributeError` 被 `except` 吞掉 |
| 2 | docx 转出 34 页二进制垃圾 | `_read_text` 多编码轮询 + `latin-1` 兜底。latin-1 对**任何**字节都成立，等于永不报错，于是把 docx（本质是 ZIP）当成纯文本读了一遍 |

修复后：

* COM 通道改正，且**失败原因如实写进转换结果消息**，不再静默降级；
* `_read_text` 显式拒绝二进制文档后缀（docx / xlsx / pdf 等），拒绝时抛错；
* 内置排版通道重写为 `mammoth → HTML → PyMuPDF Story` 多页排版，
  **显式嵌入系统中文字体**并做子集化（一页文档 10 MB → 66 KB，且保持嵌入）；
* 顺带修掉 8 个"转换成功但内容是错的"副产物问题：RTF 解析泄漏字体表、
  Office 导出 GBK/gb2312 编码、垃圾文本抢救判据过松、`DocumentWriter` 句柄未释放
  导致子集化偶发失效等。

## 二、修复：底部「开始转换」按钮上的字看不见

按钮是**白底 + 白字**，四个字完全不可见，只剩一个空边框。

根因是 **Qt 样式表在容器上的级联**：动作栏在 `QFrame` 上写了一句**没有选择器**的
`background: #FFFFFF`。Qt 会把控件上的样式表作用到它的**全部子孙**，于是一句话把
栏内三个按钮全刷成白底；而 `#PrimaryButton` 的文字色仍是白色。

> 这个 bug 存在期间，**19 项界面自测全部通过** —— 因为它们只查数据、不查像素。

## 三、界面修复与优化

| 项 | 说明 |
|---|---|
| 下拉框箭头 | 原来是引用 CSS"透明边框拼三角形"的写法，**Qt 的 QSS 不实现**，渲染成小方块。改为运行时用 QPainter 画的真箭头 |
| 复选框 | 勾选后是实心蓝方块、没有「勾」。补上勾形图形 |
| 首启动 | 空表格与空状态提示**同时显示**（`_update_empty_tip()` 构建界面时从未调用） |
| 「…」按钮 | `padding: 7px 16px` + `setFixedWidth(34)` → 内容区宽 0，文字被挤没。改为文件夹图标按钮 |
| 参数面板 | 底衬色 `#efefef` 与窗口 `#F4F6F9` 对不上（`QScrollArea` 透明对 viewport 无效） |
| 参数分组折叠 | 8 张卡片常年全展开需滚动，改为 3 展开 5 收起，状态记入 QSettings |
| 工具栏图标 | 7 个矢量图标，QPainter 现画，不引资源文件 |
| 侧栏数量徽标 | 自绘 delegate（QSS 表达不了「名称左对齐 + 数字右对齐」） |
| 空状态改版 | 图形 + 主副文案 + 两个入口 + 加密音乐能力说明 |
| 运行日志 | 默认收起，标题带条数，纵向空间留给列表 |
| 其他 | 进度条带百分比、表格斑马纹、拖拽高亮、路径框显示盘符、顶栏品牌标记 |

## 四、验证

```
selftest.py           33 项   通用转换端到端
selftest_decrypt.py   33 项   加密层逐字节比对官方金标密钥流
selftest_pipeline.py  19 项   调度链路：剥壳 → 转码
selftest_ui.py        27 项   界面集成 + 外观像素断言（本次 19 → 27）
selftest_docs.py      28 项   文档转换内容正确性（本版新增）
------------------------------------------------------------
合计                 140 项   全部通过
```

新增的两类断言，专门堵上面那两个坑：

* **文档**：PDF 文本层必须含源文档里的已知中文串、中文字体 `ext != 'n/a'`
  （真的嵌进去了）、页数合理 —— 「文件非空」不再算通过；
* **界面**：截真实窗口取像素，直接断言主按钮底色必须是品牌深蓝
  —— 把「用户能不能看见按钮上的字」变成一条会自动失败的测试。

冻结产物自检（打包时自动跑）也新增了文档转换冒烟：内置通道与高保真通道
各转一份带中文的 docx，任一路内容不对即**中断构建**。

## 安装

下载 `FormatMaster_Setup_v1.2.0.exe`（约 105 MB），双击安装。已装旧版可直接覆盖。

安装包自带 ffmpeg，无需另行配置。

## 从源码运行

```bash
git clone https://github.com/senlip/FormatMaster
cd FormatMaster
pip install -r requirements.txt
python -m app.main
```

> 仓库不含 `tools/ffmpeg/`（第三方 GPL 二进制，约 158 MB）。
> 需要视频/音频转码时请自行下载 ffmpeg 放入 `tools/ffmpeg/bin/`。
> 详见 `README.dev.md` 的开发环境一节。
